Inventario de ítems de configuración

F-08

Líneas base

F-10

Una línea base es un conjunto de ítems en un estado acordado, revisado y aprobado. A partir de ella, todo cambio pasa por el control de cambios.

Línea baseEvento que la estableceÍtems que incluye (F-08)Quién apruebaCómo se marcaCómo se reconstruye
Una buena línea base
  • Tiene nombre y fecha.
  • Dice qué ítems incluye y en qué versión.
  • Se sabe quién la aprobó.
  • Otra persona puede reconstruirla y obtener exactamente lo mismo.
git tag -a v1.0.0 -m "Línea base de entrega 1.0.0, aprobada por <rol>"
git show v1.0.0          # quién, cuándo y qué incluye
git switch --detach v1.0.0   # reconstruir el estado exacto
