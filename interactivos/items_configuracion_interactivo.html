¿Es ítem de configuración?

Gestión de Configuración y Mantenimiento de Software · Unidad 2 · Formato F-08

Catorce artefactos que aparecen alrededor de un sistema como Flask. Decida si cada uno es ítem de configuración y dónde debe vivir. No se califica: sirve para calibrar el criterio antes de hacer el inventario de su propio sistema.

El criterio

Un ítem de configuración es cualquier artefacto cuyo cambio puede afectar el comportamiento o la reproducibilidad del sistema. Lo que se genera a partir de otros ítems no se controla por separado: se controla su fuente.
