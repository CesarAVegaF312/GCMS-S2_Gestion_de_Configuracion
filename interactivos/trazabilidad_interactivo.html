Trazabilidad de una versión

Gestión de Configuración y Mantenimiento de Software · Unidad 2 · Formato F-12

Las diez entradas del registro de cambios de Flask 3.1.0, seguidas desde el motivo hasta la prueba. Cada eslabón dice si se encuentra solo con Git, si hay que buscarlo por el contenido del cambio o si vive únicamente en GitHub. Datos del repositorio público de Flask.

Resumen

Haga clic en cada entrada para ver su cadena completa.

Se encuentra solo con Git Se encuentra buscando el contenido del cambio Solo en GitHub o no existe

Cómo se obtuvo

El estado de cada entrada sale de herramientas/configuracion.py traza flask --desde 3.0.3 --hasta 3.1.0 --registro CHANGES.rst. Los commits de las entradas que no citan un PR en Git se encontraron con git log -S, buscando un identificador que el cambio introduce, y el PR con la primera fusión que lo contiene. La prueba es el archivo de tests/ que el commit modificó.

Lo que muestra Flask: un registro de cambios cuidadoso no basta. Si el vínculo entre el motivo y el cambio vive en la plataforma, la trazabilidad depende de esa plataforma. Su estrategia tiene que decir dónde vive cada vínculo.
